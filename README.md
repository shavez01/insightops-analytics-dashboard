# 📊 InsightOps Analytics Dashboard

A lightweight analytics dashboard built with Angular 21, Angular Material, and Chart.js to visualize key business metrics and KPIs.

## 🚀 Features

📈 Revenue trend line chart
📊 KPI summary cards
🎨 Angular Material UI
⚡ Standalone component architecture
📦 Chart.js integration (v4)

## 🛠 Tech Stack

- Angular 21
- Angular Material
- Chart.js + ng2-charts
- SCSS

## ▶️ Run Locally

```bash
npm install
ng serve
```
